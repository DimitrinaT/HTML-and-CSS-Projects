# HTML and CSS Projects

This repository contains a collection of HTML and CSS projects created for practice and learning purposes. Each project demonstrates different web development concepts, layouts, and interactive features, showcasing my growing skills in web design and front-end development.


## Projects

- One-Page Site  
- Space Station Site  
- Cinema Site  


### One-Page Site

This project is a responsive single-page website focused on home design, created using HTML and CSS. It features sections for the Living Room, Bedroom, and Kitchen, each with image galleries showcasing design ideas. The site also includes a contact form for visitors to get in touch and an embedded video introducing the team. 

### Space Station Site

This project is a responsive website designed for booking space trips. The site features a clean and modern layout that works well on both desktop and mobile devices. Visitors can explore a gallery showcasing spacecraft and destinations, and submit their contact information through a reservation form to book a trip. The navigation bar links to the Home, Gallery, and Reservations sections, making it easy to move around the site. Interactive elements, such as hover effects on images, buttons, and menu links, enhance the user experience. 

### Academy Cinema Site

This project is a responsive website for a movie theater, designed using HTML, CSS, and Bootstrap 4. The site features a navigation bar linking to the About, Showtimes, and Deals sections. Visitors can learn about the theater's location, seating, and sound system, see the current movies playing with detailed showtimes, and sign up for a rewards program. The design focuses on a clean layout, easy navigation, and a user-friendly experience across both desktop and mobile devices. 


## Technologies Used

These projects were built using:  

- HTML5  
- CSS3  
- Bootstrap 4  
- Embedded Multimedia Elements
